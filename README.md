# ARC Raiders — справочник квестов

Минималистичный русско-английский каталог. Статический сайт без сборки и зависимостей.

## Открыть

Откройте `dist/index.html` в браузере. Для локального HTTP-просмотра выполните `python -m http.server 4173 --directory dist` из папки проекта.

## Возможности

- 100 квестов из открытого каталога RaidTheory, полученного 13.10.2026.
- Названия и описания на русском и английском, этапы на русском.
- Карты, торговцы, награды и предыдущие задания.
- Поиск по двум языкам, фильтры, сортировка по цепочке или названию.
- Отметки этапов и квестов, сохранение в localStorage, экспорт и импорт прогресса.
- Адаптивный интерфейс и ссылки на исходные записи.

## Полнота данных

Включён полный каталог из 100 JSON-записей данного источника. Полнота относительно текущей версии игры не подтверждена. Даты обновления записей сохранены. Карты сопоставлены вручную по целям и ARC Raiders Wiki; перед будущим обновлением необходимо повторно сверить их с игрой.

Основной источник: https://github.com/RaidTheory/arcraiders-data ; https://arctracker.io . Карты: https://arcraiders.wiki/wiki/Quests . Данные распространяются по MIT; игровые материалы принадлежат Embark Studios AB.

## Sites

Содержимое `dist/` готово для статического размещения. Sites ещё не зарегистрирован и не опубликован: в рабочей среде недоступно подключение через сетевой proxy, отсутствуют локальные вспомогательные скрипты Sites. После восстановления инфраструктуры нужно создать Site, сохранить его project_id в `.openai/hosting.json`, синхронизировать исходники штатным source helper и опубликовать точный архив.
